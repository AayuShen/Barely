# Devlog: 2026-10-01, v1.1.1 (update log)

*Barely, by AayuShen*

## Context

v1.1.0 shipped with GitHub Actions running CodeQL (`security-and-quality` queries) for the
first time. The first scan raised 10 alerts. Each one was reviewed rather than bulk-dismissed.

| Alert | Verdict | Action |
|---|---|---|
| `cpp/path-injection`: diagnose file path built from `LOCALAPPDATA` | **Real** (low risk: the path is only written inside Explorer, as the same user) | Use `SHGetKnownFolderPath(FOLDERID_LocalAppData)` |
| `cpp/equality-on-floats` (3) | **Worth hardening**: XAML may store `Opacity` with less precision | Compare with a 0.001 tolerance |
| `cpp/poorly-documented-function`: settings window procedure | Style | Added a message-by-message summary comment |
| `cpp/loop-variable-changed` (2) | Intentional: the argument parser advances `i` to consume an option's value | Dismissed with explanation |
| `cpp/unused-static-function` (2) | False positive: CodeQL doesn't follow the `wmainCRTStartup` entry point of the GUI build | Dismissed with explanation |
| `cpp/long-switch` | Style: one message handler per case is the normal Win32 pattern | Dismissed with explanation |

## Verification

- MSVC `/analyze`: 0 warnings.
- `tests/run-tests.ps1`: 36/36 pass locally and in CI.
